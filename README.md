# 广东省考常识通（iPhone离线刷题PWA）

## V1.1.0 更新
- 全部291道题统一改为“单空四选一选词填空”。
- 原本以完整句子为选项的科技成果题，改为从原资料表述中挖空一个关键数字、名称或术语，选项改为短词/短语。
- 名词解释题改为在定义句中挖空核心概念。
- 其余题目保留原知识点，将问句改写为带空格的填空句。
- 保留原题ID、章节、正确答案位置、解析和PDF页码；错题、收藏和统计逻辑不变。

## 功能
- 章节练习、随机练习、错题本、收藏夹、100题模拟考试（90分钟）、答题统计。
- 本地保存答题记录；支持JSON备份和导入；部署后缓存可支持离线使用。

## iPhone安装方式（需要先部署到HTTPS地址）
1. 将整个文件夹上传到静态网站托管服务，确保 `index.html` 位于网站根目录。可使用GitHub Pages、Cloudflare Pages或其他支持HTTPS的静态托管。
2. 在iPhone上用Safari打开部署后的HTTPS网址。
3. 点击Safari分享按钮，选择“添加到主屏幕”。
4. 桌面出现“广东常识通”图标后即可启动。首次打开时保持网络连接，等待题库和离线缓存加载完成。
5. 之后可在无网络环境下刷题。定期在“学习统计”页导出JSON备份。

> iOS的PWA离线缓存和“添加到主屏幕”需要HTTPS来源（localhost开发环境除外）。直接在“文件”App中预览HTML，不等同于安装PWA，也不保证Service Worker离线缓存可用。

## 本地预览
在电脑上进入本文件夹，运行：

```bash
python3 -m http.server 8000
```

然后浏览器打开 `http://localhost:8000`。
